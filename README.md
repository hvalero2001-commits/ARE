# ARE - Automated Response Engine

## Descripción

ARE (Automated Response Engine) es un motor de respuesta automatizada para eventos de seguridad.

Su objetivo es analizar eventos, evaluar políticas, gestionar la reputación de direcciones IP y ejecutar respuestas dinámicas mediante distintos backends de firewall.

ARE está diseñado para complementar soluciones existentes, proporcionando una capa de decisión basada en políticas configurables y estados de reputación.

---

## Características

- Policy Engine
- Sistema de reputación de IP
- Estados NEW / WATCH / BANNED
- Backend de Firewall
- Persistencia mediante SQLite
- Arquitectura modular
- Logging estructurado
