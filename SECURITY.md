# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.x | ✅ Yes |
| < 1.0 | ❌ No |

---

## Reporting a Vulnerability

If you discover a security vulnerability in ARE, please do not publish it immediately.

Instead, report it privately by opening a confidential communication with the project maintainer.

Please include:

- Description of the vulnerability
- Steps to reproduce
- Impact assessment
- Suggested mitigation (if available)

The report will be reviewed and addressed as quickly as possible.

Thank you for helping improve the security of ARE.
