## RFC - Request for Comments

Las ideas de arquitectura o cambios importantes deberán proponerse primero como RFC.

Un RFC no es una tarea inmediata. Es una propuesta para discusión, análisis y aceptación futura.

### Estados posibles

- Draft
- Accepted
- Rejected
- Implemented

### Ejemplos

- RFC-001: Renombrar CLI oficial a `are`
- RFC-002: Backend Manager
- RFC-003: Captura de eventos `Found` desde Fail2Ban
- RFC-004: Reputation Decay Engine
